How every report is built

  • The simple analogy first, then the maths.
  • Hypotheses (H₀ and Hₐ) written before any result, tested with p-values, effect sizes and confidence intervals.
  • Leak-free evaluation (cross-validation with the preprocessing inside the pipeline) and honest limitations.
  • Each report is a rendered Jupyter notebook; the source notebook and project README live on GitHub.
